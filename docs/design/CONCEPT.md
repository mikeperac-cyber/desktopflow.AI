# Phase 1 visual concept brief

Generated with the built-in image generation tool as a `ui-mockup` design specification.

## Final prompt

Design DeskFlow AI as a practical Windows 11 desktop application shown in two complete states: a compact centered Spotlight command overlay and a full Settings window. Keep every control implementable as code-native React/Tailwind UI. Use a refined Windows-native direction with dark graphite surfaces, cool slate borders, near-white type, muted gray secondary text, one electric-blue accent, 12–16px window radii, soft layered shadows, and Segoe UI/Inter-like typography. The overlay contains the DeskFlow AI name, four-point sparkle, focused command input, current status, and keyboard hints. Settings contains General, AI, Automation, Privacy, and Advanced navigation; System/Light/Dark appearance; Open DeskFlow and Emergency stop shortcuts; opt-in launch at startup; Cancel and Save settings. Keep the composition lightweight, calm, readable, and keyboard-first. Avoid gradients, glassmorphism, marketing content, pills, badges, fake metrics, unrelated panels, illustrations, stock imagery, macOS controls, and invented product claims.
